# CNC Builder AI

Arabic/English CNC design estimator and preliminary drawing generator.

## Hosting
This is a static web application. Upload `index.html` to a GitHub repository and enable GitHub Pages from the main branch and root folder.

## Dependencies
The browser loads Three.js, jsPDF, and JSZip from CDNs, so internet access is required.

## Important
Outputs are preliminary estimates and drawings, **not verified manufacturing plans**. Engineering validation is necessary before cutting or building machinery.

Saved projects use browser localStorage and do not sync between devices.
